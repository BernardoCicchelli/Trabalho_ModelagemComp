Métodos para equações não lineares e sistemas lineares

Método da Falsa Posição

Encontra uma raiz de f(x) = 0 dentro de um intervalo [a, b] em que f troca de sinal.

Como funciona
xr = ( xl·f(xu) − xu·f(xl) ) / ( f(xu) − f(xl) )
  • Traça a reta que liga (xl, f(xl)) a (xu, f(xu)); o ponto onde ela corta o eixo x é a nova aproximação xr.
  • O extremo que tem o mesmo sinal de f(xr) é substituído por xr, e o processo se repete.
  • Condições: f contínua em [xl, xu] e f(xl)·f(xu) < 0 (Teorema de Bolzano) — se isso falhar, não há garantia de raiz no intervalo.
  • A convergência é linear (ordem 1); é comum um dos extremos nunca ser substituído (ficar "preso").
1 Problema
Inserir:
Use * para multiplicar e ** (ou ^) para potência. Exemplo: cos(x) - x.
2 Parâmetros
Extremo esquerdo do intervalo
Extremo direito (maior que a)
Quanto menor, mais preciso
Evita repetir para sempre

Critério de parada: erro relativo |xr − xr,anterior| / |xr| ≤ tolerância (mostrado em fração e também em %). O slide também cita |xu − xl| ≤ tolerância como alternativa; este programa usa o erro relativo entre xr consecutivos, como no exemplo do slide (a Conclusão de cada cálculo explica o porquê). Os números aceitam 0,5, 1e-8, 1/3 e pi/2.

Método de Newton-Raphson

A partir de um chute inicial x₀, usa a reta tangente para chegar cada vez mais perto de uma raiz de f(x) = 0.

Como funciona
xi+1 = xi − f(xi) / f′(xi)
  • Interpretação geométrica: a fórmula é a reta TANGENTE ao gráfico em xi (a aproximação de Taylor de 1ª ordem de f em torno de xi); xi+1 é onde essa tangente corta o eixo x.
  • A derivada f′(x) é calculada automaticamente (simbolicamente) e mostrada no resultado.
  • Condições: f derivável, f′(xi) ≠ 0 em cada passo (senão o método não pode continuar) e x₀ suficientemente próximo da raiz (convergência local).
  • Numa raiz simples a convergência é quadrática (ordem 2); numa raiz múltipla vira linear.
1 Problema
Inserir:
Use * para multiplicar e ** (ou ^) para potência. Exemplo: cos(x) - x.
2 Parâmetros
Quanto mais perto da raiz, melhor
Ex.: 1e-2 significa 1e-2 % = 0,0001 em fração
Evita repetir para sempre

Critério de parada: erro relativo |xi+1 − xi| / |xi+1| × 100 ≤ tolerância, já em PORCENTAGEM — igual ao pseudocódigo do slide. Os números aceitam 0,5, 1e-8, 1/3 e pi/2.

Eliminação de Gauss com pivoteamento parcial

Resolve um sistema linear Ax = b transformando-o em um sistema triangular.

Como funciona
Li ← Li − mi·Lk,   mi = aik / akk
  • Em cada coluna k, a linha com maior |aik| é trazida para a posição do pivô (pivoteamento parcial).
  • Os elementos abaixo do pivô são zerados com os multiplicadores mi; depois a solução sai por substituição retroativa.
  • Determinante = produto dos pivôs × (−1)trocas de linha.
  • Se não há pivô, o sistema é classificado pelo Teorema de Rouché-Capelli: impossível ou indeterminado.
  • Com o pivoteamento desligado, cada etapa k usa sempre a linha k; se o elemento akk for nulo, o programa avisa (em vez de dividir por zero).
1 Sistema Ax = b
Sistema n × n, de 1 a 10
Preencha cada coeficiente de A e o termo independente b. Aceita frações (1/3) e vírgula decimal (0,5).
2 Opções
Desligue para reproduzir um exemplo "sem pivoteamento" (ordem natural das linhas)
Frações exatas não aceitam π, e nem raízes irracionais
Arredonda após CADA operação (mostra o efeito de pivô pequeno). Vazio = sem arredondar.
