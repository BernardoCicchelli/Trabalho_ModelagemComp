Cálculo Numérico

Métodos para equações não lineares e sistemas lineares

Método da Falsa Posição

Encontra uma raiz de f(x) = 0 dentro de um intervalo [a, b] em que f troca de sinal.

Como funciona
xk = ( a·f(b) − b·f(a) ) / ( f(b) − f(a) )
  • Traça a reta que liga (a, f(a)) a (b, f(b)); o ponto onde ela corta o eixo x é a nova aproximação xk.
  • O extremo que tem o mesmo sinal de f(xk) é substituído por xk, e o processo se repete.
  • Condições: f contínua em [a, b] e f(a)·f(b) < 0 (Teorema de Bolzano).
  • A convergência é linear (ordem 1).
1 Problema
Inserir:
Use * para multiplicar e ** (ou ^) para potência. Exemplo: cos(x) - x.
2 Parâmetros
Extremo esquerdo do intervalo
Extremo direito (maior que a)
Quanto menor, mais preciso
Evita repetir para sempre

Critério de parada: erro relativo |xk − xk−1| / |xk| ≤ tolerância. Os números aceitam 0,5, 1e-8, 1/3 e pi/2.

Método de Newton-Raphson

A partir de um chute inicial x₀, usa a reta tangente para chegar cada vez mais perto de uma raiz de f(x) = 0.

Como funciona
xk+1 = xk − f(xk) / f′(xk)
  • Em cada passo, a tangente ao gráfico em xk corta o eixo x em xk+1.
  • A derivada f′(x) é calculada automaticamente (simbolicamente) e mostrada no resultado.
  • Condições: f derivável, f′(xk) ≠ 0 e x₀ suficientemente próximo da raiz (convergência local).
  • Numa raiz simples a convergência é quadrática (ordem 2); numa raiz múltipla vira linear.
1 Problema
Inserir:
Use * para multiplicar e ** (ou ^) para potência. Exemplo: cos(x) - x.
2 Parâmetros
Quanto mais perto da raiz, melhor
Quanto menor, mais preciso
Evita repetir para sempre

Critério de parada: erro relativo |xk − xk−1| / |xk| ≤ tolerância. Os números aceitam 0,5, 1e-8, 1/3 e pi/2.

Eliminação de Gauss com pivoteamento parcial

Resolve um sistema linear Ax = b transformando-o em um sistema triangular.

Como funciona
Li ← Li − mi·Lk,   mi = aik / akk
  • Em cada coluna k, a linha com maior |aik| é trazida para a posição do pivô (pivoteamento parcial).
  • Os elementos abaixo do pivô são zerados com os multiplicadores mi; depois a solução sai por substituição retroativa.
  • Determinante = produto dos pivôs × (−1)trocas de linha.
  • Se não há pivô, o sistema é classificado pelo Teorema de Rouché-Capelli: impossível ou indeterminado.
1 Sistema Ax = b
Sistema n × n, de 1 a 10
Preencha cada coeficiente de A e o termo independente b. Aceita frações (1/3) e vírgula decimal (0,5).
